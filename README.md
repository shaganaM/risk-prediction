# Cardiac Arrest Risk Prediction System ❤️

## 📌 Description
This project predicts the risk of cardiac arrest using important medical parameters such as blood sugar, blood pressure, CK-MB, and troponin levels.

## 💻 Tech Stack
- Python
- Flask

## ⚙️ Features
- Predicts Low / Medium / High Risk
- Uses medical indicators
- API-based system

## 📊 Parameters Used
- Blood Sugar
- Blood Pressure (BP)
- CK-MB
- Troponin

## 📊 Sample Input
{
  "blood_sugar": 200,
  "bp": 150,
  "ckmb": 30,
  "troponin": 0.5
}

## 📈 Output
High Risk

- Apply Machine Learning algorithms (Logistic Regression, Naive Bayes)
